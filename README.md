# Kiln

Personal hypertrophy coach for a push, pull, legs week, with runs beside the lifts.

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:8080.

## Notes

- Workout logs, aims, and a Strava access token are stored in the browser, not in this repo.
- Strava pull needs an access token from https://www.strava.com/settings/api.
- The coach chat needs `XAI_API_KEY` in the environment.
